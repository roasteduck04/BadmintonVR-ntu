Where the frames come from

Tick the angles to use: only these are calibrated (step 2) and streamed (step 3). 3 angles keep real time at 60 fps; 4–5 are more accurate and slower. 1 angle = the 1-camera mode (testing): court position ~10–15 cm, rough pose, no racket / shuttle 3D; player heights under "One camera" in step 3.

One row per camera. The names are yours (each names its calibration file, data/calib/<name>_cam.json); the clip above only sets the game type and the stream settings. Test grabs one frame from every camera. One camera works too (the 1-camera mode, for testing).
