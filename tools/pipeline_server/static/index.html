Simulated live broadcast

          
The videos are played as if the cameras were live. Every frame goes through 2D pose, 3D and the
            body fit the moment it arrives, and its JSON file appears in the run's unity_live_frames/ folder;
            Unity shows each pose as soon as its file lands.

Court calibration

        Pick a camera on the left, click court points on the frame (pick the point on the court
          diagram first), Auto finds the field of view, Save writes data/calib/<camera>_cam.json
          (the old one is archived). Below 15 px is good. Calibrate again whenever a camera moves.

      
    

    

      
Camera sync (fixed cameras)

      
The stream lines the cameras up in time. With sync file (best_live) it uses offsets measured
        once from the clip's offline build; with auto it estimates them in the first 2 s (1–2 frames off).
